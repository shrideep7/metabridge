Agent approvals

A runner can never approve their own actions — only withdraw them. Owners and admins approve or reject.
Consequential agent actions are held here until a different, permissioned approver signs off. Read-only analysis commits on its own; anything that generates artifacts or changes a system waits for a decision.
A decision recorded against the person who requested the run is a withdrawal, not an approval — the server refuses self-approval, so that is the only decision a runner can make on their own request.

Bucket region is only needed for SAP HANA sources: HANA puts it in the URI scheme (s3-ap-south-1://) where every other platform takes a plain s3://. Leave it blank and the HANA unload comes out with a <region> placeholder to fill in by hand.
Named source credential is the PURPOSE of a credential you create once on the source — CREATE CREDENTIAL FOR COMPONENT 'SAPHANAIMPORTEXPORT' PURPOSE 'MB_S3' … on SAP HANA. It is a name, not a secret: the key stays in the source system and never reaches a generated file.
